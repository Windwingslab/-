# MotionHub —— AE 脚本插件合集平台

风翮 windwings 出品的 After Effects 扩展面板（CEP），用来：

- 提供一套**常用工具**：锚点、缓动、克隆关键帧、对齐分布、图层、表达式、复制合成、收集颜色
- **整理**你所有的 `.jsx` / `.jsxbin` 脚本和 `.ffx` 预设：分类、搜索、一键运行
- 把常用脚本**固定到工具页**，像自带工具一样一键运行

支持 After Effects 2020 及以上（Windows / macOS）。

## 安装

1. 解压后，保持 `com.windwings.motionhub` 文件夹和安装脚本在同一个目录。
2. 运行对应系统的安装脚本：
   - **macOS**：双击 `安装-Mac.command`。如果提示"无法打开"，就右键 → 打开 → 再点一次「打开」。
   - **Windows**：双击 `安装-Windows.bat`。
3. **完全退出** After Effects 再重新打开，然后在菜单 **窗口 → 扩展 → MotionHub** 打开面板，拖进工作区停靠。
4. 第一次使用前，请在 AE **首选项 → 脚本和表达式** 里勾选 **「允许脚本写入文件和访问网络」**，否则无法添加脚本。

安装脚本做了两件事：

- 把插件复制到扩展目录：
  - macOS：`~/Library/Application Support/Adobe/CEP/extensions/`
  - Windows：`%APPDATA%\Adobe\CEP\extensions\`
- 开启 Adobe 的 `PlayerDebugMode`，允许加载没有签名的扩展。

**卸载**：删除上面扩展目录里的 `com.windwings.motionhub` 文件夹即可。

> 如果之前装过旧版 `MotionHub.jsx`（ScriptUI 面板），请把它从 `Scripts/ScriptUI Panels` 里删掉，以免和新版混淆。

## 使用

鼠标移到任意按钮上，**面板底部的提示栏**会显示它的用法。很多按钮按住修饰键点击有不同功能：

| macOS | Windows |
| --- | --- |
| ⌥ Option + 单击 | Alt + 单击 |
| ⇧ Shift + 单击 | Shift + 单击 |
| ⌘ Command + 单击 | Ctrl + 单击 |

所有操作都能用 Cmd/Ctrl + Z 一步撤销。

### 添加你自己的脚本

- 在工具页 **MY SCRIPTS** 里点 **＋**，或者在脚本库页点 **添加脚本**。
- 选好文件后选择分类，勾选 **「显示在工具页」**，它就会作为一个按钮出现在 MY SCRIPTS 里。
- 脚本库里已有的脚本，鼠标移上去点 **图钉** 就能固定到工具页，再点一次取消固定。

### 脚本库页

- 脚本库就是一个普通文件夹（默认是 `文稿/MotionHub/Library`），**每个子文件夹就是一个分类**。直接往里面放文件后点「刷新」即可。
- 鼠标移到某一行会出现四个按钮：固定到工具页、在文件夹中显示、移除（移到 `_已移除` 文件夹，可恢复）、运行。也可以双击整行运行。
- 在脚本开头的注释里写 `@name` / `@desc` / `@author`，库里就会显示名称和说明：

```js
/*
    @name   批量修改合成设置
    @desc   在项目面板选中多个合成，一次性修改帧率、时长、尺寸。
    @author 你的名字
*/
```

### 设置页

- **更换脚本库文件夹**：可以选网盘同步文件夹，多台电脑共用一套脚本。
- 检查「允许脚本写入文件」权限，打开 ScriptUI Panels 文件夹，重新导入示例脚本。

## 视觉规范（风翮 windwings）

- 四色：画布 `#171819`、唯一强调色 `#FF5900`、橙的暗部 `#26110A`、白；文字 `#F4F4F2` / 副文 `#8A8C8E`
- 字体：Geist / Geist Mono（联网时自动加载，离线时回退到系统字体）
- 章节头 `(01) — ANCHOR` 用橙色等宽字，分隔只用 1px 线，不用阴影
- 橙色块上一律用近黑图标和文字（白字对比度不达标）
- 交互：悬停时按钮变亮、图标变橙；按下时缩小到 0.96，普通按钮变橙底，橙色块变深棕底

## 文件结构

```
MotionHub/
├── com.windwings.motionhub/   插件本体
│   ├── CSXS/manifest.xml      扩展声明
│   ├── index.html · css/ · js/  面板界面
│   ├── jsx/host.jsx           在 AE 里执行的工具和脚本库逻辑
│   └── library_seed/          首次启动导入的示例脚本
├── 安装-Mac.command
└── 安装-Windows.bat
```
