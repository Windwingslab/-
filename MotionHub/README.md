# MotionHub —— AE 脚本插件合集平台

一个可停靠的 After Effects 面板，用来：

- **整理**你所有的 `.jsx` / `.jsxbin` 脚本和 `.ffx` 预设（按分类、可搜索、可收藏）
- **一键运行**脚本，或把预设应用到选中图层
- **安装**新脚本：导入到脚本库，可选同时安装到 AE 的 ScriptUI Panels
- 提供一套**常用基础工具**（锚点、缓动、对齐、图层、表达式）

支持 After Effects CC 2018 及以上（Windows / macOS）。

---

## 安装

1. 把整个 `MotionHub` 文件夹里的内容（`MotionHub.jsx` 和 `MotionHub_Library` 文件夹）复制到：
   - **Windows**：`C:\Program Files\Adobe\Adobe After Effects <版本>\Support Files\Scripts\ScriptUI Panels\`
   - **macOS**：`/Applications/Adobe After Effects <版本>/Scripts/ScriptUI Panels/`
2. 打开 AE：**编辑（macOS 为 After Effects）→ 首选项 → 脚本和表达式**，勾选 **「允许脚本写入文件和访问网络」**。
3. 重启 AE，在 **窗口** 菜单最下方点 **MotionHub.jsx**，把面板拖进你的工作区停靠即可。

> 第一次打开时，`MotionHub_Library` 里的示例脚本会自动复制到你的脚本库：`文档/MotionHub/Library`。

## 功能

### 工具

| 分组 | 功能 |
| --- | --- |
| 锚点 | 九宫格：把锚点移到图层的四角、四边中点或中心，图层位置不变；居中到合成；空对象父级 |
| 缓动 | 缓入缓出、缓入、缓出、线性、定格；可调「影响 %」 |
| 对齐到合成 | 左 / 水平中 / 右 / 上 / 垂直中 / 下；水平分布、垂直分布 |
| 图层 | 新建空对象 / 调整层 / 纯色 / 摄像机；按帧数依次排列；剪到工作区；逐个预合成；反转顺序；批量重命名 |
| 表达式 | 抖动 wiggle、循环 loop、往返 pingpong、弹性回弹、清除表达式 |

每个操作都可以用 `Ctrl/Cmd + Z` 一步撤销。鼠标停在按钮上会显示说明。

### 脚本库

- 脚本库就是一个普通文件夹，**里面每个子文件夹就是一个分类**。可以直接往里面放文件，然后点「刷新」。
- 顶部下拉框可以按分类筛选，也可以只看「★ 收藏」；搜索框会同时搜名称、描述和分类。
- **双击**或点「▶ 运行」：`.jsx` / `.jsxbin` 直接运行；`.ffx` 预设应用到当前选中图层。
- 「安装…」：选择文件 → 选择分类或新建分类 → 复制进库。勾选「同时安装到 ScriptUI Panels」时会复制到当前 AE 版本的用户面板目录，重启 AE 后在「窗口」菜单可见。
- 「移除」不会直接删除，而是移到库里的 `_已移除` 文件夹（以 `_` 开头的文件夹不会被扫描）。

### 设置

- **更换脚本库文件夹**：可以指向网盘同步目录（如坚果云、OneDrive），多台电脑和团队就能共享同一套脚本。
- 检查「允许脚本写入文件」权限；打开 ScriptUI Panels 文件夹；重新导入示例脚本。

## 让你的脚本在库里显示说明

在脚本开头的注释里写上这几个标记即可（可选）：

```js
/*
    @name   批量修改合成设置
    @desc   在项目面板选中多个合成，一次性修改帧率、时长、尺寸。
    @author 你的名字
*/
```

没有 `@name` 时显示文件名。脚本里如果有 `instanceof Panel`，类型会显示为「面板」。

## 附带的示例脚本

| 分类 | 脚本 | 作用 |
| --- | --- | --- |
| 合成 | 批量修改合成设置 | 一次修改多个合成的帧率 / 时长 / 尺寸 |
| 图层 | 随机错开时间 | 选中图层在 N 帧内随机错开 |
| 文字 | 文本查找替换 | 批量替换文字图层内容 |
| 项目 | 整理项目面板 | 素材按类型归入文件夹 |
| 渲染 | 批量添加到渲染队列 | 选中合成一次加入渲染队列，可统一输出目录 |

## 注意事项

- 对齐、居中、分布会**跳过带父级的图层**（父级坐标系不同）。
- 锚点和对齐按当前时间指示器所在帧计算；位置有关键帧时，会整体平移所有关键帧。
- `.jsxbin` 是加密脚本，无法读取说明信息，只显示文件名。
- 编辑脚本文件时请保存为 **UTF-8 带 BOM** 编码，否则中文可能乱码。
